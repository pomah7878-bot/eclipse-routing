# ECLIPSE Routing

Готовые сплит-туннелинг профили роутинга (direct / proxy / block) для клиентов **Happ**,
используемые в **ECLIPSE Unlimited VPN**.

## Что внутри

- `geo/geosite.dat`, `geo/geoip.dat` — компактные geo-базы (домены/IP), собранные для
  экономии памяти в туннеле на слабых устройствах, где стандартные полные базы
  (Loyalsoldier v2ray-rules-dat и т.п.) вызывают ошибку `лимит памяти туннеля превышен`.
- `HAPP/DEFAULT.JSON` — профиль маршрутизации "ECLIPSE RU": российские сервисы и
  локальная сеть идут напрямую, остальной трафик — через прокси.

## Использование

В приложении Happ выбери **Настройки → Маршрутизация → Добавить конфигурацию** и укажи
ссылку на файл `HAPP/DEFAULT.JSON` из этого репозитория (raw.githubusercontent.com),
либо профиль подставляется автоматически ботом ECLIPSE через заголовок `routing`
подписки.

## Источник

Geo-базы форкнуты из открытого проекта [mvrvntn/routing](https://github.com/mvrvntn/routing)
(без указанной лицензии на момент форка). Профиль JSON адаптирован и переименован под
бренд ECLIPSE. Все правки списков доменов/IP ведутся независимо от исходного проекта.

## Дисклеймер

Репозиторий содержит только технические списки доменов и IP-адресов для оптимизации
маршрутизации трафика (снижение задержки, разгрузка туннеля) и не является средством
обхода блокировок.
